POCKETSMART AI - READY TO RUN

1. Double-click START_POCKETSMART.bat
2. The website opens automatically at http://127.0.0.1:8010
3. Create an account and log in.
4. Use Home, Party, or Jewelry Planner.
5. The app works in fallback/demo mode without a Gemini API key.
6. Keep the black terminal window open while using the site.

This copy uses port 8010 so it will not conflict with an older PocketSmart server on port 8000.
